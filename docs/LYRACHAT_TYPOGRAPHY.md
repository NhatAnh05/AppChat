# LyraChat – Cập nhật kiểu chữ

- Font chính: Nunito Sans (400/500/600/700/800), fallback Segoe UI → Arial.
- Đã tinh chỉnh tiêu đề, sidebar, danh sách hội thoại, nội dung tin, nhập liệu, thông báo và cài đặt.
- Font được lấy từ Google Fonts khi có Internet; nếu không tải được, trình duyệt tự dùng Segoe UI/Arial.
- Không thay đổi WebSocket, thông báo hoặc xử lý gửi nhận tin nhắn.
- Chạy: npm install; npm run dev:full.
